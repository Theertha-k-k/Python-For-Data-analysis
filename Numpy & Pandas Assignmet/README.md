This project demonstrates the use of NumPy and Pandas libraries in python language
NumPy (Numerical Python) to perform temperature data analysis using one-dimensional (1D) and two-dimensional (2D) NumPy arrays.
The project focuses on creating arrays, understanding their properties, performing temperature conversions, calculating statistical values, and extracting specific data using array indexing and slicing.

Pandas library in Python to create, explore, filter, analyze, and manipulate transactional data.
A sample transaction dataset containing 10 records is used to understand various Pandas DataFrame operations. The project focuses on practical data analysis techniques that are commonly used in real-world data analytics projects.
